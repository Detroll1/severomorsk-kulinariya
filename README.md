# Кафе-кулинария, Североморск

Сайт кафе-кулинарии на ул. Пионерской, 22: меню по категориям, сборщик комплексного обеда с расчётом выгоды, меню на неделю, доставка и контакты. Тёмная тема, живой пар над супом на canvas, анимации при прокрутке.

Живой сайт: https://detroll1.github.io/severomorsk-kulinariya/

Сделали вместе: Detroll и Николай ([Quorvox](https://github.com/Quorvox)), его демо — https://quorvox.github.io/cookingseveromorsk-demo/

Чистые HTML, CSS и JavaScript, без библиотек и внешних CDN. Блюда и цены правятся в начале `app.js`.
